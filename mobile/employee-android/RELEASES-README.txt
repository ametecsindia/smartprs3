SmartPRS3 mobile app
====================

SmartPRS3 Mobile app - one app for everybody. After sign-in it shows exactly what that login has on
                       the web: an employee sees their own screens and data, an Admin / HR login sees
                       its menus, approvals, edit and delete options. Register the phone with an
                       Employee ID or a SmartPRS login email; phones are approved / revoked in
                       SmartPRS3 > Administration > Mobile Devices.

Each version has its own folder (v1.0, v1.1 ...). File names end in -debug or -release:
  -debug    built with Build > Build APK(s); fine for testing and for your own phones.
  -release  signed build for giving to clients.

These copies are made automatically: every time Android Studio builds an APK it is also
saved here (a newer build of the same version replaces the older file).
