## 5. Excluded — named as a counter-example, not declared

A sentence can name a code in order to say it is **not** a permission — R-XXII-013 names `payroll.run.approve.hyderabad` as the string the catalogue validator must reject. Read as a declaration, such a sentence puts in this register the very code the corpus says must never exist. These occurrences were skipped. The exclusion is listed rather than silent so a wrong skip is visible; **still used** means the code is declared elsewhere and remains in the register above.

| Code | Part | Still used | Sentence that excluded it |
|---|---|---|---|
| `payroll.run.approve.hyderabad` | XXII | **no** | `payroll.run.approve.hyderabad` is a schema error, rejected by the catalogue validator, because Hyderabad is a **scope**, not a capability. |
